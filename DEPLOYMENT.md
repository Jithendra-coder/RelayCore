# Deployment

## Local sandbox

The supported runnable setup is the loopback-only Docker Compose Demo Mode described in [README.md](README.md). It uses sandbox actions and static demo API keys. Do not expose it to the public internet or use it for shared production data.

## Production configuration contract

Production requires a UTF-8 PostgreSQL database and all of the following environment values:

- `DATABASE_URL`: managed PostgreSQL connection string with TLS and a least-privilege role.
- `RELAYCORE_DEMO_MODE=0`.
- `RELAYCORE_OIDC_ISSUER`, `RELAYCORE_OIDC_CLIENT_ID`, `RELAYCORE_OIDC_CLIENT_SECRET`, and `RELAYCORE_OIDC_REDIRECT_URI`.
- `RELAYCORE_OIDC_STATE_SECRET`: random signing key with at least 32 characters.
- `RELAYCORE_SECRET_ENCRYPTION_KEY`: Fernet key generated by `Fernet.generate_key()` and injected from a secret manager. Losing this key makes stored webhook and workspace credentials unusable.
- Optional `RELAYCORE_OIDC_DISCOVERY_URL`; by default it is derived from the issuer.
- `RELAYCORE_AUTH_SESSION_SECONDS`: 300–604800 seconds, default 43200.

Issuer, discovery, and redirect URLs must use HTTPS. Register the exact callback `/auth/callback` at the identity provider and serve the UI over HTTPS so the secure session cookie is sent. Put secrets in a secret manager; do not commit them to `.env` or source control. The OIDC provider flow has not been live-tested because provider credentials are not available here.

## Deployment status

There is no staging or production infrastructure, Terraform, image publishing, migration rollout, rollback automation, or cloud smoke test yet. A production release is blocked until provider-backed workflow actions and those deployment controls are implemented and verified. See [LIMITATIONS.md](LIMITATIONS.md).
